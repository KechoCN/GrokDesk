GrokDesk 浏览器连接（Chrome / Edge）

1. 保持 GrokDesk 打开。
2. Chrome 地址栏输入 chrome://extensions；Edge 输入 edge://extensions。
3. 开启「开发者模式」，选择「加载已解压的扩展程序」，选择本文件所在文件夹。
4. 在同一浏览器打开 https://grok.com 并登录。已经打开的网页请刷新一次。
5. 返回 GrokDesk 的 Chat。消息、网页当前可见历史、昵称和头像会自动同步。

升级 GrokDesk 后请在扩展管理页点击本扩展的刷新按钮。
语音、屏幕共享、支付、模型切换及官网无法识别的控件，请使用 Chat 右上角的「在浏览器中继续」。
扩展通过当前用户的本机连接传递可见网页内容。不会读取 Cookie、浏览器密码或登录令牌。
不要分享此文件夹或其中的 config.js；其中包含当前安装的本机连接密钥。
