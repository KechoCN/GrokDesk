# GrokDesk 0.1.0

统一 Windows、macOS、Linux 的首个跨平台版本。

- 完整 Build 工作区、Grok 原版 TUI、附件与文件预览、任务进度、技能/插件上下文。
- Chrome/Edge 扩展连接已登录的 Grok 网页，支持 Chat 与账号展示。
- 平台原生窗口行为、Command/Ctrl 快捷键、桌面 CLI 查找和文件剪贴板适配。
- Linux 自带开源中文字体回退，界面和终端无需额外下载字体。
- x64/ARM64 独立发行文件、原生终端验证记录与 SHA-256 校验。

按系统及 CPU 架构选择附件。Linux x64 的 AppImage 名称使用 `x86_64`，deb 使用 `amd64`；Apple Silicon 与其他 ARM64 设备选择对应系统的 `arm64` 文件。Build 需要另行安装 Grok Build。

Windows 包未使用发布者证书签名，macOS 为 ad-hoc 签名、未 Apple 公证。具体签名与运行验证状态以各目标 `*-build.json` 为准。六组发行包必须通过原生 CI、包内终端读写和 SHA-256 校验后才会汇集发布；真实 Grok 账号登录与付费服务未纳入隔离回归测试。

升级后重新加载浏览器扩展并刷新 Grok 页面。版本号按统一发布计划重定为 0.1.0，保留原有系统用户数据；若旧安装器拒绝降版本，可先卸载旧程序且保留用户数据，再安装此版本。

GrokDesk 是独立非官方客户端，不隶属于 xAI、X Corp. 或 ZCode。
