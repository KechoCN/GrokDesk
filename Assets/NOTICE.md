# Grok mobile app icon

Source: [Grok AI on Apple's App Store](https://apps.apple.com/us/app/grok-ai/id6670324846), app ID 6670324846.

`grok-mobile.png` contains the mobile app artwork. `GrokDesk.ico` provides standard Windows icon sizes.

`GrokDesk.icns` and `linux/512x512.png` package the same attributed PNG for macOS and Linux without changing its pixels. Regenerate those containers with `npm run icons:generate`.
